# Overview
This is the software artifact for the COLM 2026 paper "Quasar: A Programming Language Specialized for LLM Code Actions" by Mell et al., generating its figures and plots.

It consists of components doing each of the following:
- Generate Python and Quasar-subset programs for each task
- Compile the Quasar-subset programs into Quasar
- Execute programs, recording external call results (e.g. LLMs and image models)
- Execute programs sequentially, replaying external calls
- Execute programs with autoparallelization, replaying external calls
- Execute programs with approval batching, replaying external calls
- Execute programs with conformal semantics
- Build figures and plots

The only results not reproduced are the "Nano" rows from Figure 3b, which involve a fine-tuned version GPT-4.1-nano that can't be redistributed.

Some components are nondeterministic or expensive, so the outputs used in the paper are included. For example, building the figures and plots from the included execution results reproduces those in the paper.

The Quasar interpreter code (`./epic/`) is adapted from the [Opal artifact](https://doi.org/10.5281/zenodo.16929280).

# Build figures and plots
The only prerequisite is [uv](https://docs.astral.sh/uv/). Set up minimal dependencies:
```bash
uv sync
```
Regenerate paper figures and plots from the included executions:
```bash
rm -rf plots/
./gen_figs_all.sh plots/
```

# Full setup
Additional setup is required for other pipeline stages:
```bash
# Extra deps (torch/transformers), needed only for GQA conformal execution and --record runs.
# CPU suffices for the local models.
uv sync --extra record

# Note the first GQA execution of any kind downloads the GQA val images (~3 GB) from
# HuggingFace, and GQA --record/conformal also fetch the OWLv2 + CLIP weights (~1.8 GB).

# Needed only for the LLM-backed stages: program generation, and AgentDojo/GQA/BCP recording.
export OPENAI_API_KEY=...

# Pin set ordering to match the recorded runs (all verification runs assume this).
export PYTHONHASHSEED=0

# BCP only: fetch and decrypt the BrowseComp-Plus corpus with upstream's own script (~1.9 GB,
# deletable afterwards), then stage the 80 sampled problems (not shipped).
curl -sL https://raw.githubusercontent.com/texttron/BrowseComp-Plus/0f060ef0cd82eac2ebdb8a5b8c2ed5c677008cee/scripts_build_index/decrypt_dataset.py | uv run python - --output decrypted.jsonl
uv run python extract_bcp_problems.py decrypted.jsonl

# Shorthands for the dataset dirs the commands below write into.
GQA=datasets/gqa_val/gpt-5/epic_compiled
AD=datasets/agentdojo/gpt-5/epic_compiled
BCP=datasets/bcp/epic_compiled/0
```
# Generate Python and Quasar-subset programs for each task
Needs `OPENAI_API_KEY`. LLM generation is nondeterministic, so these likely will not match the included programs. Note that overwriting the included programs makes the included recordings and execution results stale for them; the later stages regenerate those. This stage is expensive: ~1,180 programs generated by gpt-5, each with up to 4-5 checker-guided attempts (hours of wall clock and substantial API cost).

```bash
# GQA (also regenerates the sampled-questions file, written when the loop completes)
rm -rf $GQA/progs_py datasets/gqa_val/gpt-5/val_n1000_seed2025.json
uv run python generate_gqa.py --num_samples 1000 -k epic_compiled --model_name gpt-5 -p --regenerate checker --num_attempts 4 --rerun

# AgentDojo
for s in workspace banking slack travel; do rm -rf $AD/$s/progs_py; done
uv run python generate_agentdojo.py -k epic_compiled --model_name gpt-5 --regenerate checker --num_attempts 5 --rerun

# BrowseCompPlus (no --rerun flag; it always regenerates)
rm -rf $BCP/progs_py
uv run python generate_bcp.py -t 0 -k epic_compiled
```
# Compile the Quasar-subset programs into Quasar
```bash
# GQA opportunistic
rm -rf $GQA/progs_epic $GQA/info_compilation
uv run python translate_gqa.py

# AgentDojo opportunistic
for s in workspace banking slack travel; do rm -rf $AD/$s/progs_epic $AD/$s/info_compilation; uv run python translate_agentdojo.py --suite $s; done

# BrowseCompPlus opportunistic
rm -rf $BCP/progs_epic
uv run python translate_bcp.py

# GQA conformal
rm -rf $GQA/progs_set
uv run python -m eval.set_patcher -d $GQA -s prog

# AgentDojo conformal
for s in workspace travel; do rm -rf $AD/$s/progs_set; uv run python -m eval.set_patcher -d $AD/$s -s py -r; done
```

# Execute programs, recording external call results (e.g. LLMs and image models)
Recording runs live (nondeterministic, needs `OPENAI_API_KEY`) and replaces the included recordings that the replay stages below consume. GQA records all 1000 programs; each BCP program makes hundreds of sequential gpt-5-nano calls (~5-15 minutes per program).
```bash
# GQA
rm -rf $GQA/recordings/4o_all $GQA/exec/4o_all_epic_replay
uv run python run_gqa.py -e --record

# AgentDojo
for s in workspace banking slack travel; do rm -rf $AD/$s/recordings $AD/$s/exec_py; uv run python run_agentdojo.py --suite $s -p --record; done

# BrowseCompPlus
rm -rf $BCP/recordings $BCP/exec_py
uv run python run_bcp.py -p --record
```

# Execute programs sequentially, replaying external calls
Replays sleep each call's recorded latency, so the sequential GQA and BCP replays take hours of wall clock in total.
```bash
# GQA
rm -rf $GQA/exec/4o_all_py_replay
uv run python run_gqa.py -p

# AgentDojo
for s in workspace banking slack travel; do rm -rf $AD/$s/exec_py_replay; uv run python run_agentdojo.py --suite $s -p --replay; done

# BrowseCompPlus
rm -rf $BCP/exec_py_replay
uv run python run_bcp.py -p --replay
```
